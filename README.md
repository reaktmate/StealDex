# Contributing to StealDex

StealDexへの貢献を歓迎します！

StealDexは、Robloxの「Steal a ○○」系ゲームを対象とした、オープンソースのアイテム図鑑・交換募集画像メーカーです。

このプロジェクトでは、特にアイテム情報の追加・修正を歓迎しています。

## 1. 貢献できること

### アイテムデータへの貢献

以下のような貢献を歓迎します。

- 新しいアイテムの登録
- アイテム名やレア度の修正
- 入手方法や説明文の追加・修正
- アイテムの分類や検索情報の改善
- ゲームのアップデートに伴う情報の更新
- データの誤りや重複の報告

データを追加・修正する場合は、確認できる出典や情報の確認日を可能な範囲で記載してください。

### バグ報告・機能提案

GitHub Issuesから、バグや改善案を報告できます。

報告する際は、再現手順、期待した動作、実際の動作などを記載してください。

### コードへの貢献

コードの改善提案も歓迎します。ただし、コードの設計・採用・リリースについては、プロジェクトオーナーが最終判断を行います。

大きな変更を実装する前に、Issueで提案内容を相談してください。

## 2. アイテムデータの追加・修正

データの形式は、既存のJSONファイルとスキーマに従ってください。

原則として、以下を守ってください。

- 既存のIDと重複しないIDを使用する
- 対象ゲームを明確にする
- 必須項目をすべて記載する
- 正式名称と確認できる情報を使用する
- 不確かな情報を確定情報として登録しない
- 既存アイテムの重複登録を避ける
- 変更したデータ以外を不要に書き換えない

画像を追加する場合は、その画像の権利と利用条件を確認してください。利用許可が不明な画像は追加しないでください。

具体的なJSON形式やファイルの配置については、各データディレクトリの説明に従ってください。

## 3. Pull Requestの手順

1. リポジトリをForkします。
2. 変更内容に合ったブランチを作成します。
3. 必要なデータやコードを変更します。
4. 変更内容を確認し、可能な範囲で検証します。
5. Pull Requestを作成します。
6. レビューで指摘があれば修正します。

Pull Requestには、変更内容、変更理由、関連するIssue、情報の出典を記載してください。

アイテムデータのみの変更では、コードを変更せずにデータの修正だけを提案して構いません。

## 4. 採用とレビュー

すべての提案を採用することを保証するものではありません。

以下の観点から、プロジェクトオーナーが採用可否を判断します。

- 情報の正確性
- 出典や権利関係の明確さ
- 既存データとの整合性
- プロジェクトの目的との適合性
- 保守性と安全性

大きな機能追加や設計変更は、実装前に合意を得ることを推奨します。

## 5. ライセンスと権利

本プロジェクトのコードは、リポジトリに記載されたGNU Affero General Public License v3.0 or later（AGPL-3.0-or-later）の条件に従います。

貢献者は、自分が権利を有するコードやデータのみを提出してください。他者のコードや素材を提出する場合は、ライセンスと再利用条件を確認してください。

Pull Requestを提出する前に、変更内容が本プロジェクトのライセンス条件の下で公開されることを確認してください。

特別な合意がない限り、貢献者が自分の著作権をプロジェクトオーナーへ譲渡することは求めません。

なお、ゲーム内画像、ロゴ、キャラクターなどの権利は、本プロジェクトのコードライセンスとは別に扱います。

## 6. 行動規範

すべての参加者に対して、敬意を持って対応してください。

- 他の参加者への嫌がらせや攻撃をしない
- 個人情報を無断で公開しない
- 虚偽の情報や悪意のある変更を提出しない
- 権利を侵害する素材を持ち込まない
- IssueやPull Requestで建設的な議論を行う

プロジェクトオーナーは、コミュニティの安全とプロジェクトの品質を守るため、問題のある投稿や貢献を拒否する場合があります。

## 7. 質問・連絡

質問や不具合の報告は、GitHub Issuesを利用してください。

StealDexをより便利なサービスにするため、ご協力をよろしくお願いします！
